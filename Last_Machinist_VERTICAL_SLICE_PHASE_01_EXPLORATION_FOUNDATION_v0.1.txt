LAST MACHINIST
VERTICAL SLICE — PHASE 01
EXPLORATION FOUNDATION v0.1
CODEX DEVELOPMENT SPEC

[목표]
MVP/PATCH 단계 이후 첫 Vertical Slice.
이번 단계에서는 탐색 콘텐츠 전체가 아니라 다음 기반만 구현한다.

1. 기존 메인 UI에 [탐색] 탭 추가
2. 탐색 탭에서 지역 선택용 지도 구현
3. 선택 지역의 3D Scene 진입
4. 1인칭 3D 기본 이동 구현
5. 작업장 복귀 및 재진입

완료 루프:
작업장 → 탐색 탭 → 지도 → 지역 선택 → 탐색 시작
→ 1인칭 3D 이동 → 작업장 복귀 → 다시 탐색 가능

============================================================
1. 탐색 탭
============================================================

기존 UI 탭 구조를 AUDIT한 뒤 동일한 규칙으로 [탐색] 탭을 추가한다.

Player-Facing 텍스트:
탐색

탐색 탭 선택 시 지역 선택용 지도 UI를 표시한다.
기존 가공/퀘스트/메모/측정 UI 기능은 재작성하지 않는다.
PATCH_003의 UI 정렬/Anchor 규칙을 유지한다.

============================================================
2. 지도
============================================================

이번 지도는 '탐색 지역 선택 화면'이다.
완성형 월드맵 시스템을 만들지 않는다.

최소 구성:
- 지도 표시 영역
- 탐색 가능 지역 Marker
- 선택 지역 정보
- [탐색 시작] 버튼

Marker 클릭:
→ Region Selected

지역 미선택:
→ 탐색 시작 불가

지역 선택:
→ [탐색 시작] 활성
→ 클릭 시 해당 Exploration Scene 진입

Phase 01은 테스트 지역 1개만 있어도 PASS다.

향후 지역 추가가 가능하도록 최소 Region 데이터 구조를 둔다.

예:
RegionId
DisplayName
SceneReference 또는 SceneName
IsUnlocked
Description(optional)

지역 하나를 위해 Scene 이름과 UI 전체를 여러 코드에 중복 하드코딩하지 않는다.

============================================================
3. 테스트 탐색 지역
============================================================

Greybox 수준으로 만든다.

최소:
- 바닥
- 벽/경계
- 단순 구조물 또는 장애물
- Player Spawn Point
- 작업장 복귀 기능

이번 단계의 목적은 아트가 아니라
탐색 진입/이동/복귀 루프 검증이다.

복잡한 환경을 Unity Primitive로 억지 제작하지 않는다.
필요 이상의 환경 아트는 만들지 않는다.

============================================================
4. 3D 시점
============================================================

탐색 지역은 1인칭 3D 시점이다.

탐색 Scene 진입:
- First Person Camera 활성
- Player Spawn
- 탐색 Input 활성

가공 화면의 Orthographic 4 View와 분리한다.
가공 Camera 시스템을 탐색 Camera로 억지 재사용하지 않는다.

============================================================
5. 기본 조작
============================================================

W = 전진
S = 후진
A = 좌측 이동
D = 우측 이동

마우스 이동 = 1인칭 시점 회전

마우스 좌클릭 = Interact

이번 Phase의 핵심은 기본 이동이다.

점프 / 앉기 / 대시 / 스태미나 등은 구현하지 않는다.

============================================================
6. 이동 요구사항
============================================================

- WASD 정상 이동
- Camera 방향 기준 자연스러운 이동
- 벽/장애물 Collision
- 기본 Gravity
- 바닥 관통 없음
- Spawn Point에서 시작
- 마우스 X = 좌우 Look
- 마우스 Y = 상하 Look
- Pitch 제한으로 화면 뒤집힘 방지

Mouse Sensitivity는 여러 코드에 흩어져 하드코딩하지 않는다.

현재 프로젝트의 Input System과 Player 구조를 먼저 AUDIT하고
호환되는 CharacterController/기존 방식을 사용한다.
중복 입력 시스템을 만들지 않는다.

============================================================
7. INTERACT
============================================================

Interact 입력은 마우스 좌클릭으로 확정한다.

Phase 01에서는 향후 탐색 상호작용에서 사용할
Interact Command/Input 경로까지만 확보한다.

Left Mouse Click
→ Interact

향후 필요 시 Camera 중앙 기준 Interaction Ray와 연결할 수 있게 한다.

이번 단계에서는 다음을 구현하지 않는다:
- 아이템 회수
- 재료 식별
- NPC 대화
- 컨테이너
- 장비 획득
- 상세 조사 UI

============================================================
8. 작업장 복귀
============================================================

탐색 Scene에서 [작업장 복귀] 기능을 제공한다.

[작업장 복귀]
→ Exploration Scene 종료/전환
→ 기존 Workshop/Main 복귀
→ 기존 UI 정상 복원

복귀 후 다시:
탐색 탭 → 지도 → 탐색 시작
이 가능해야 한다.

복잡한 귀환 조건은 이번 단계에서 만들지 않는다.

============================================================
9. 권장 시스템 분리
============================================================

Workshop/Main:
- 기존 가공 시스템
- Quest
- Memo
- [탐색] 탭
- 지도

Exploration:
- FirstPersonPlayer
- FirstPersonCamera
- Greybox Environment
- SpawnPoint
- ReturnToWorkshop

현재 Scene Manager/전환 구조가 이미 있다면 우선 재사용한다.

============================================================
10. OUT OF SCOPE
============================================================

이번 Phase에서 구현하지 않는다.

- 자원 회수
- 인벤토리
- 재료 식별
- 재료 광택/마킹 판별
- 장비 회수
- NPC
- 적
- 전투
- 체력/스태미나
- 생존 시스템
- 랜덤 이벤트
- 차량
- 탐색 범위 확장
- 완성형 대형 맵
- QUEST 02 본편
- 고품질 환경 아트

Codex는 위 기능을 임의로 추가하지 않는다.

============================================================
11. CODEX 구현 순서
============================================================

STEP 1 — AUDIT
현재 Main/Workshop Scene, UI 탭, Scene 전환, Input System,
Player Controller, Canvas/Layout 구조를 확인한다.

STEP 2 — EXPLORATION TAB
기존 UI 규칙에 맞춰 [탐색] 탭 추가.

STEP 3 — MAP
Region Marker + Selected 상태 + [탐색 시작] 구현.

STEP 4 — REGION DATA
향후 지역 추가 가능한 최소 Region 데이터 구조 구성.

STEP 5 — EXPLORATION SCENE
Greybox 테스트 지역 1개 생성.

STEP 6 — FIRST PERSON
WASD + Mouse Look + Collision + Gravity 구현.

STEP 7 — INTERACT INPUT
좌클릭 Interact 입력 경로 추가.
콘텐츠는 아직 연결하지 않는다.

STEP 8 — ENTRY
지도 선택 지역 → Exploration Scene 진입.

STEP 9 — RETURN
[작업장 복귀] → Workshop/Main 복귀.

STEP 10 — LOOP
진입 → 이동 → 복귀 → 재진입 반복 검증.

============================================================
13. PASS
============================================================

- [탐색] 탭 존재
- 지도 표시
- 지역 선택 가능
- 선택 후 탐색 시작 가능
- 1인칭 3D Scene 정상 진입
- WASD 정상
- Mouse Look 정상
- Collision/Gravity 정상
- 좌클릭 Interact 입력 기반 존재
- 작업장 복귀 가능
- 재진입 가능
- 향후 지역 추가 가능한 최소 구조
- 기존 가공/측정/Quest/UI 손상 없음

============================================================
14. FAIL
============================================================

- 탐색 탭이 기존 UI를 깨뜨림
- 지역 선택 없이 탐색 시작
- 탐색 Scene에서 Camera/Input 비활성
- WASD 이동 이상
- 벽 통과
- Look Pitch 뒤집힘
- 작업장 복귀 불가
- 복귀 후 재진입 불가
- 테스트 지역 하나에 모든 Region 로직 하드코딩
- 이번 범위를 넘어 인벤토리/전투 등을 임의 구현
- 기존 선반/측정/Quest 회귀 버그

16. 완료 정의
============================================================

플레이어가 기존 작업장에서 [탐색] 탭을 열고,
지도에서 지역을 선택해 3D 탐색 Scene으로 진입한 뒤,
1인칭 시점에서 WASD와 마우스로 정상 이동하고,
작업장으로 돌아와 다시 탐색할 수 있으면 Phase 01 완료다.

이번 단계에서는 그 이상을 구현하지 않는다.
