# 치수 합격 후 진행 막힘 확인

사용자 저장 파일을 읽기 전용으로 확인했다. 저장된 형상은 L1 Ø40×30, L2 Ø50×40, L3 Ø40×30으로 정확하며 FinalInspection 상태였다. Chamfers가 비어 있어 기존 필수 모따기 조건에서 Reworkable 판정이 발생한다.

기존 '추가 절삭 또는 모따기 필요' 문구를 치수 불합격과 모따기 누락으로 분리했다. 치수가 맞으면 명시적으로 '직경과 길이는 합격'을 표시한다. 검사 후 상단의 '추가 작업 → 선반으로' 버튼을 추가하고 가공 중 검사 항목을 안내한다.

저장 파일·공작물 형상을 수정하거나 자동 합격시키지 않았다. 런타임 컴파일 및 실제 가공/모따기 명령을 거치는 펌프 수리 도메인 회귀 검증 PASS. UI 실제 실행 확인은 남아 있다.
