# 가공·검사 진행 연결 수정

- 가공 시작/종료 버튼을 왼쪽 제목 바로 아래, 스크롤 영역 밖으로 이동했다.
- 회전 중에는 종료를 비활성화하고 같은 상단 영역에서 주축을 정지할 수 있다.
- 종료 시 FinalInspection 상태로 전환하고 곧바로 측정 페이지를 연다.
- 최종 측정 페이지 상단의 '측정 완료 → 형상 판정'은 기존 실제 Geometry 판정을 실행하고 결과 페이지로 이동한다.
- 합격 시 상단 '납품 진행 → 작업장'에서 기존 농장 납품 동선으로 이어진다. 불합격이면 기존 재가공/소재 재시도를 사용한다.
- 플레이어 기록을 정답으로 보정하거나 형상을 복원하지 않는다.

런타임 컴파일 성공. Boot 테스트에 주축 회전 중 종료 차단 및 종료 후 측정 페이지 전환 검증을 반영했다. 실제 Unity 플레이 확인은 남아 있다.
