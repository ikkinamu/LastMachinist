# MVP v0.4 적용 및 검증 — 2026-09-14

## 기준과 범위

사용자가 지정한 `Last_Machinist_MVP_Development_Spec_v0.4.txt`를 현재 MVP 동작 기준으로 적용한다. 중복되는 이전 설명보다 60 → 61 → 48/61.6 → 40 이후 상세 → 이전 요약 순서를 따른다. AGENTS의 데이터 분리, 재료 제거, 입력 명령 계층 및 MVP 제외 범위는 유지한다. 구현 계획의 기존 8단계 통합 보완 작업이며 후속 게임 시스템을 추가하지 않는다.

## 기존 구현 점검에서 확인한 문제

- 작업장 장식이 가공·측정·메모 화면 위에도 그려졌다. 농장 맥락은 뒤이어 그리는 펌프 배경 사각형에 가려졌다. 이전 v0.3 보고서의 '핵심 화면을 가리지 않는다'는 설명은 시각 검증으로 입증되지 않았다.
- 시작 대화가 전체 화면 중앙에 있었고, 이후 대화 위치도 장소마다 달랐다. 대화 중 키보드 가공 입력은 별도로 차단되지 않았다.
- 카메라는 초기화 시 직교였지만 이후 갱신 시 투영을 보장하지 않았다.
- 고장 L3의 직경만 줄었고 길이는 항상 30 mm였다.
- 입력칸 초기값은 `0`이었다. 측정 재시도·현재 공작물 기록 목록으로 이어지는 명시적 조작이 부족했다.
- 테스트 어셈블리를 누락한 외부 런타임 컴파일만으로 Unity 전체 컴파일 성공을 단정할 수 없었다.

## 변경

- 장소 개요 페이지와 가공·측정 페이지를 분리했다. 배경은 장소 개요/대화에서만 표시되며, 명시적 GUI 레이어로 대화와 페이지 순서를 정했다.
- `DialoguePage`가 시작 선택지와 이후 대화를 모두 화면 하단 33%에 표시한다. 인물은 작업복/회색 머리와 농장 모자/앞치마로 구분한 임시 삽화다. 대화는 기존 카탈로그를 사용한다.
- 대화 시작 시 명령 라우터를 비활성화하고 종료 후 이전 가공 컨텍스트를 복귀한다. 측정 페이지에서는 이동·주축 입력이 차단된다.
- 의뢰 시작/완료 및 아이템 획득은 일정 시간만 표시하는 알림이며, 현재 목표는 작은 추적창, 상세는 사용자가 여는 의뢰 페이지에 표시한다.
- 네 고정 시점은 모두 실제 `Camera.orthographic`을 설정하며, 카메라 뷰포트와 하단 핸들 영역을 분리했다. 휠 줌은 추가하지 않았다.
- `VernierDisplayModel`/`VernierView`를 분리했다. 죠 간격과 부척은 기기값으로 움직이며 결과 숫자를 자동 표시하지 않는다. 입력은 비워 두고 비유한 입력만 거부한다. 틀린 유한 값은 그대로 저장한다.
- 측정 위치 강조, 현재 공작물 기록 목록, 다시 측정, 가공/작업장 복귀를 연결했다. 고장품의 작업 메모는 제조 중 기록과 별도로 유지한다.
- 고장 축 끝 2.5 mm를 재료가 없는 형상으로 표현했다. 길이 측정은 선택 구간에 실제 남아 있는 재료의 양 끝을 사용한다. 따라서 새 고장품의 L3 길이는 27.5 mm로 표현되며 원형 30 mm를 자동 표시하지 않는다. 이전 저장의 Geometry는 강제로 변경하지 않는다.
- 환경 장식의 가림을 제거하고 작업장 선반/작업대/소재/공구/기록, 농장 작물/탱크/배관 및 펌프 모터 핀/커플링/유입관/고정 요소를 보강했다.

## 검증

- Unity 6000.6.0f1 실제 EditMode 실행: **79 통과, 0 실패, 0 건너뜀**. `Build/v04-validation/unity-results.xml`, `unity-tests.log`.
- 테스트에는 Boot 진입, 두 끝 가공, 챔퍼, 실제 형상 판정, 설치 중 저장 복원, 펌프 복구가 포함된다. 사용자의 실제 저장 슬롯을 쓰지 않는다.
- 새 테스트: 네 View의 직교 유지 및 깊이에 따른 투영 크기 동일, 측정 중 주축·이동 차단, 빈 입력 초기값, 기기 눈금 정렬 및 기록 독립, L3 직경/길이 마모, 하단 대화 영역.
- Unity의 실제 참조·정의·C# 버전을 사용한 런타임 및 Editor 테스트 전체 컴파일도 수행했다. 신규 파일을 포함하도록 응답 파일을 생성했다.
- 별도 그래픽 캡처를 위해 개발용 Windows 실행 파일도 빌드했다. 빌드는 성공했지만 아래 이유로 시각 검증은 통과 처리하지 않았다. 캡처용 임시 소스는 프로젝트에서 정리했다.

## 완료 판정의 제한

79개 테스트의 통과가 명세 전체의 최종 시각 품질을 입증하지 않는다. 환경/인물은 절차적으로 그리는 임시 삽화이고, 펌프 음향은 임시 합성음이다. 정식 아트·조명·환경음 품질, 모든 해상도의 수동 조작, 실제 UI 저장/불러오기, 명세의 전체 시작 연출·설정·일시정지 페이지는 별도 완료 근거가 필요하다. 따라서 v0.4 전체 MVP 또는 Presentation 완성을 선언하지 않는다.
