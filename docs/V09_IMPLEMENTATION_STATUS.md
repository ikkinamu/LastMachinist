# v0.9 적용 — 2026-09-17

## 반영

- 첫 퀘스트 평가 생성 시 Perfect ±0.25mm, Functional ±1mm 및 실제 구간 길이 평가를 명시했다. 일반 부품의 Functional 기본값은 ±0.5mm로 분리했다.
- 길이 측정은 지정 구간의 중간 위치에 있는 실제 원통 구간을 찾고, 동일 반경의 인접 구간을 합쳐 실제 어깨 좌표로 계산한다. 미가공 봉처럼 어깨가 없으면 전체 연속 구간 길이가 측정된다. 숫자로 목표 길이를 대신 넣지 않는다.
- 실제 구간 범위를 직경 평가에도 사용해 허용 범위의 어깨 이동을 고정 목표 경계의 직경 오차로 잘못 탈락시키지 않는다.
- 측정 위치 선택 → 공작물 접촉/확대 눈금 → 직접 입력 → 기록/재측정 → 복귀 순으로 측정 페이지를 재배치했다. 선택 위치를 강조하고 위치 선택 시 입력칸을 비운다.
- 가공 메뉴/F1/작업장 가공 버튼/소재 선택은 MachineSelect 페이지로 진입한다. 선반만 조건부 활성화하며 밀링·드릴링은 준비 중 비활성 버튼이다. 측정에서 진행 중 가공으로 복귀하는 경로는 유지한다.

## 검증

- 런타임과 Editor 테스트 코드 컴파일 확인.
- 독립 실행 검증 PASS: 실제 L1 길이 27.6mm, 버니어 갱신, 잘못 입력한 기존 기록 유지, 허용 범위의 어깨 이동·직경 오차, 일반 공차와 퀘스트 공차 분리.
- 기존 반복 측정/재고 소모/재시도/추론 도메인 검증 PASS.
- V09Tests 추가. Boot 테스트에 소재 선택 후 장비 선택 페이지 확인을 반영했다. Unity UI 실행 테스트는 이번에 수행하지 않았다.

## 남은 사항

- PROP_Pump_Broken.png / PROP_Pump_Repaired.png가 없어 기존 자산 슬롯과 임시 펌프 표현을 유지했다. 최종 아트가 아니다. 별도 Pump Interactive Prop 자식 GameObject가 상태별 이미지를 보관하고 월드 UI가 표시한다. 퀘스트 상태는 기존 도메인이 소유한다.
- 현재 구간 식별은 지정 영역 중간점을 기준으로 한다. 극단적으로 구간 경계가 이동해 기준점이 다른 구간에 포함되면 해당 실제 구간을 측정하므로, 임의 다단 형상의 자유 측정 기능을 의미하지 않는다.
- 실제 UI 배치·눈금 가독성과 전체 Unity 플레이 검증이 남아 있다. v0.9 전체 완료로 판정하지 않는다.
