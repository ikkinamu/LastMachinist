# 해상도 대응 후속 수정

범위: 기존 MVP 화면 표시 결함 수정. 다음 페이즈는 시작하지 않음.

## 수정

- `MvpUiScale`: 화면 중앙의 동일 비율 영역을 UI·카메라·입력 판정이 공유한다. 화면 가장자리에는 검은 여백을 실제로 그린다.
- `LathePrototype`: 선반 카메라 픽셀 영역을 공통 좌표로 계산하며, 휠 가공 입력은 해당 영역 안에서만 받는다.
- `MvpStartupOverlay`: 타이틀과 플레이 화면에서 여백을 덮는다.
- 두 NPC PNG의 `.meta`: 이전 수정에서 잘못된 DefaultTexturePlatform 들여쓰기를 복구하고 기본 텍스처 압축을 해제했다. GUID는 유지했다.
- `UiResolutionTests`: 종횡비·중앙 배치·카메라와 UI 정렬·사이드바 입력 제외를 검증하는 Editor 테스트 추가.

## 검증

- 런타임 및 Editor 테스트 어셈블리 컴파일 성공. 기존 obsolete API 경고 4개가 남아 있다.
- 실제 `MvpUiScale` 소스와 Unity 좌표 타입을 사용한 독립 실행 검증: 1280×800, 1920×1080, 1024×768, 2560×1080, 800×1280 모두 PASS.
- 이는 좌표 계산 검증이다. 이번 작업에서는 Unity Play 화면 캡처, NPC 재임포트 결과 및 Editor 테스트 실행까지 확인하지 않았다.
- 임의 NPC 도형은 제거된 상태를 유지한다. 별도 World NPC 이미지가 없어 대화 외 월드 캐릭터 표현은 아직 비어 있다. 새 Placeholder는 추가하지 않았다.
