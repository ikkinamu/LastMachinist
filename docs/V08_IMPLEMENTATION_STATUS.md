# v0.8 반영 — 2026-09-16

최신 사용자 요청에 따라 Section 97–103을 적용했다. 기존 MVP 범위에서 화면/목표 표시를 수정했다.

- 제공된 `Lathewheel.png`를 `Assets/_Project/Art/External/UI/Lathe/Handwheel/UI_Lathe_Handwheel_Wheel.png`로 복사했다. 원본은 보존했다.
- EnvironmentArt 바인딩에 휠 및 고정 베이스 슬롯을 추가했다. 같은 휠 PNG를 X/Z에 사용하며, 축 이름과 칸은 고정되고 이미지와 포함된 손잡이만 회전한다. 기존 드래그→LatheInputRouter 경로를 유지한다.
- 코드로 그리던 휠 대신 이미지를 표시한다. 휠이 누락되면 이를 명시하는 문구를 표시한다.
- 별도 `UI_Lathe_Handwheel_Base.png`는 제공되지 않았다. 고정 베이스 슬롯은 비어 있으며 완성된 조립 외형으로 판정하지 않는다. 손잡이는 휠 원본에 포함되어 별도 파일을 만들지 않았다.
- 모든 진행 단계의 현재 목표를 v0.8 문구로 매핑했다. 상태 변경 이벤트를 통해 갱신되며, 완료 시 빈 목표 및 Tracker 숨김을 적용했다.
- 목표 갱신 시 작은 Tracker를 2.5초 강조한다. 기존 대화/상세 페이지 숨김 정책을 유지한다. 전체 단계 목록은 상세 Quest 페이지에만 있다.

검증: 런타임 컴파일 및 기존 퀘스트 게이트/반복 측정 도메인 검증 수행. 실제 Unity에서 휠 회전 중심·투명 배경·외형·클릭 및 Tracker 시각 확인은 아직 하지 않았다. 기존 1280×800 IMGUI 레이아웃도 유지되어 상속된 Canvas 전환 요구까지 완료한 상태는 아니다.
