============================================================ 0. 목표

Phase 01~04의 탐색 → 회수 → 인벤토리 → 가공 루프를 반복해서 사용할 수
있는 선반 가공 반복 퀘스트 5종을 구현한다.

루프: Quest Window → 반복 의뢰 확인 → 수락 → 적합한 인벤토리 공작물 선택
→ 선반 가공 → 측정/검사 → 납품 → 완료 → 새 조건으로 재등장

반복 퀘스트는 QUEST 01 같은 메인/튜토리얼 퀘스트와 분리한다.

============================================================ 2. 반복
퀘스트 데이터 구조
============================================================

RepeatableQuestTemplate: - TemplateId - DisplayName -
ClientType/ClientName - Description - PartType - AllowedVariants -
RequiredFeatures - RewardDefinition(optional) - Repeatable = true

RepeatableQuestInstance: - QuestInstanceId - TemplateId -
GeneratedVariant - GeneratedTargetGeometry - GeneratedTolerance -
State - AssignedWorkpieceInstanceId(optional) - MachinedResult
reference - EvaluationResult

완료된 QuestInstance를 다시 Active로 되돌려 재사용하지 않는다. 같은
Template이 재등장하면 새로운 QuestInstance를 생성한다.

============================================================ 3. 생성
방식 ============================================================

완전 무작위 형상 생성보다 Template별 검증된 Preset Variant를 우선한다.

각 Template에 2~4개의 가공 가능한 Variant를 둘 수 있다. 현재
TurningProfile, 공구, 측정, 평가 시스템으로 실제 제작 가능한 조건만
사용한다.

불가능한 형상/공차 생성 금지.

============================================================ 4. 반복
퀘스트 01 — 마모된 펌프 보조축
============================================================

배경: 농업용 펌프의 마모된 보조축 교체품 제작.

형상: 3구간 단차축. ØA — ØB — ØC

주요 요소: - 외경 황삭 - 외경 정삭 - 단차 가공 - 길이/직경 측정

조건: 목표 최대 직경과 전체 길이보다 충분히 큰 원형 봉재 필요.

Tracker 예: - 펌프 보조축용 공작물을 준비하세요. - 첫 번째 단차를
가공하세요. - 가공한 외경을 측정하세요. - 완성품을 검사하세요. - 완성된
보조축을 납품하세요.

============================================================ 5. 반복
퀘스트 02 — 교체용 연결핀
============================================================

배경: 농기계/작업장 장치의 회전 연결부용 핀 제작.

형상: 단순 원통 또는 짧은 단차 핀.

주요 요소: - 외경 정삭 - 목표 직경 맞추기 - 길이 관리 - 모따기 - 측정

특징: 형상은 단순하지만 직경 공차를 상대적으로 중요하게 사용 가능.

Tracker 예: - 연결핀용 공작물을 선택하세요. - 외경을 목표 치수로
가공하세요. - 끝단을 정리하세요. - 직경을 측정하세요. - 연결핀을
납품하세요.

============================================================ 6. 반복
퀘스트 03 — 가이드 롤러축
============================================================

배경: 간단한 이송 장치나 가이드 롤러를 지지할 교체 축 제작.

형상: 구멍이 없는 2~3구간 단차 실축.

예: - 몸통 ØA → 지지부 ØB - 또는 끝단 ØA → 몸통 ØB → 끝단 ØA

주요 요소: - 외경 황삭 - 외경 정삭 - 단차 가공 - 외경/길이 측정 - 필요
Variant에서 외측 끝단 45° 모따기

중요: 기존 거리조정 슬리브는 중공 형상이므로 현재 미구현인 드릴/내경
가공이 필요해 Phase 05에서 제거한다.

Phase 05 반복 퀘스트 03은 다음 기능을 요구하지 않는다. - 드릴 -
센터드릴 - 리머 - 보링 - 내경 가공 - 내경 측정 - 나사 가공

현재 실제 구현된 외경 가공, 단차, 외측 45° 모따기, 외경/길이 측정
범위에서만 Variant를 생성한다.

Tracker 예: - 가이드 롤러축용 공작물을 준비하세요. - 몸통 외경을
가공하세요. - 지지부 단차를 가공하세요. - 주요 치수를 측정하세요. -
필요한 끝단을 모따기하세요. - 가이드 롤러축을 납품하세요.

============================================================ 7. 반복
퀘스트 04 — 베어링 지지축
============================================================

배경: 회전 장치의 베어링을 지지할 교체 축 제작.

형상: 몸통 ØA → 베어링 자리 ØB → 끝단 ØC

주요 요소: - 황삭/정삭 - 단차 위치 관리 - 특정 구간 정밀 가공 - 반복
측정 - 과절삭 방지

기존 평가 시스템이 구간별 가중치를 지원하면 베어링 자리의 중요도를 높일
수 있다. 지원하지 않으면 평가 엔진을 억지로 재작성하지 않는다.

Tracker 예: - 베어링 지지축용 공작물을 선택하세요. - 몸통 구간을
가공하세요. - 베어링 자리 구간을 정삭하세요. - 베어링 자리 직경을
측정하세요. - 완성품을 납품하세요.

============================================================ 8. 반복
퀘스트 05 — 밸브 조작축
============================================================

배경: 펌프나 배관 장치의 밸브 조작부에 사용할 교체 축 제작.

형상: 2~3구간 단차축 + 끝단 모따기.

예: 몸통 ØA → 조작부 ØB → 끝단 ØC + 끝단 모따기

주요 요소: - 외경 황삭 - 외경 정삭 - 단차 가공 - 끝단 모따기 - 길이/직경
측정 - 여러 구간의 치수를 순서대로 관리

특징: 나사 가공처럼 아직 구현 여부가 확정되지 않은 기능을 요구하지
않는다. 현재 구현이 확인된 기본 외경/단차 가공과 PATCH_001의 접촉식 45°
모따기를 활용한다.

Variant마다: - 구간 수 - 각 구간 직경 - 각 구간 길이 - 모따기 요구 위치

를 현재 TurningProfile과 측정 시스템이 처리 가능한 범위에서 변경할 수
있다.

Tracker 예: - 밸브 조작축용 공작물을 준비하세요. - 몸통 구간을
가공하세요. - 조작부 단차를 가공하세요. - 지정된 끝단을 모따기하세요. -
주요 직경을 측정하세요. - 밸브 조작축을 납품하세요.

============================================================ 9. 공작물
요구 조건 ============================================================

반복 Quest는 Phase 04의 실제 Player Inventory WorkpieceInstance를
사용한다.

최소 검사: - 선반 호환 ShapeType - 초기 직경 >= 목표 최대 직경 - 초기
길이 >= 목표 전체 길이 - Available 상태 - 필요한 최소 가공 여유

크기가 부족하면: “이 공작물은 목표 형상을 가공하기에 크기가 부족합니다.”

사용 가능한 공작물이 없으면: “사용 가능한 공작물이 없습니다. 탐색에서
적합한 공작물을 확보하세요.”

무료 테스트 소재 자동 생성 금지.

============================================================ 10.
재료/상태 처리
============================================================

Phase 05에서 재료 식별 시스템은 구현하지 않는다. Unknown Material의 내부
정답을 UI에 공개하지 않는다.

WorkpieceInstance의: - CorrosionCondition - SurfaceCondition -
ShapeIntegrity - DefectIntegrity - OverallConditionScore

는 유지하고 어떤 공작물을 사용했는지 Quest/Evaluation에서 추적 가능하게
한다.

이번 Phase에서는 이 점수로 복잡한 절삭 결과를 계산하지 않는다.

============================================================ 11. Quest
Window / 반복 생성
============================================================

별도 자동 Popup을 만들지 않는다. 기존 Quest Window 안에 반복 의뢰를
표시한다.

권장 구분: - 메인/스토리 퀘스트 - 반복 의뢰

상태: Offered → Active → Completed

초기 규칙: - 동시에 Offered 반복 의뢰 최대 3개 - 완료 후 빈 슬롯에 새
반복 의뢰 생성 - 같은 Template 재등장 가능 - 동일 Template은
Offered/Active 상태로 동시에 중복 생성하지 않음 - 새 Instance 생성 시
검증된 Variant 재선택

============================================================ 12. 납품 /
평가 ============================================================

기존 평가 시스템을 최대한 재사용한다.

최소 판정: - 올바른 Active Quest와 연결된 결과물 - 목표 형상/필수
Feature - 핵심 치수 허용공차 - 필요한 가공 Feature

PASS: Quest Completed → 반복 슬롯 갱신 가능

FAIL: Quest Active 유지 → 기존 평가 원칙에 따라 피드백

새로운 별도 평가 엔진을 Quest별로 만들지 않는다.

============================================================ 13. 보상

현재 확정된 경제 시스템이 없다면 Phase 05를 위해 돈/평판 시스템을 새로
만들지 않는다.

최소: - Quest 완료 기록 - 반복 의뢰 완료 횟수(optional) - 기존 Reward
시스템이 있다면 재사용

향후 확장을 위한 RewardDefinition Hook은 허용한다.

============================================================ 22. 완료
정의 ============================================================

기존 Quest Window에서 5종의 반복 의뢰를 수락하고, Player Inventory의
적합한 WorkpieceInstance를 실제 선반에서 가공한 뒤, 기존 평가 시스템으로
검사/납품할 수 있어야 한다.

완료 후 새로운 조건의 QuestInstance가 다시 Offered될 수 있어야 하며,
기존 QUEST 01, 탐색, 인벤토리, 선반, 측정 기능이 유지되면 Phase 05
완료다.

반복 퀘스트의 과도한 Target 길이를 소형 수리 부품 규모로 재조정한다.

일반 규칙: - 일반 반복 Quest Target Total Length 권장: 40~120 mm. -
상대적으로 긴 축 Variant: 최대 150 mm. - 기본 반복 Quest에서 300 mm급
Target 생성 금지. - 150 mm 초과 장축은 향후 별도 장축 가공 Quest에서만
명시적으로 허용.

Inventory Stock은 Target보다 길 수 있다. 그러나 Stock 길이를 그대로
Quest Target 길이로 사용하면 안 된다.

적합성: stock length >= target required length

Variant: - 각 Quest Template은 검증된 소형 치수 Preset 사용. -
카메라/선반/Handwheel/측정 범위에서 실제 플레이 가능한 치수만 허용. -
원재료가 길다는 이유로 완성품 길이를 불필요하게 늘리지 않는다.

PASS: - 일반 Variant가 40~120 mm 중심. - 긴 축 Variant도 150 mm 이하. -
Inventory Stock 적합성 검사 유지.

FAIL: - 일반 반복 Quest에서 300 mm Target 생성. - Stock 전체 길이를
Target으로 강제. - 카메라/선반 범위를 벗어나는 Variant. - 완료에 필요
없는 긴 봉재 전체 가공을 요구.
