LAST MACHINIST — POST-MVP PATCH 001
PATCH_001_CHAMFER_TOOL_45DEG_CONTACT_CUTTING

기준 문서:
Last_Machinist_MVP_Development_Spec_v0.10_REVIEWED.txt

상태:
Post-MVP / Vertical Slice Expansion

목적:
모따기 바이트의 형상 및 절삭 동작을 수정하여,
플레이어가 45° 모따기 바이트를 실제 공작물 모서리에 접촉시키고
직접 이송한 결과로 모따기 형상이 생성되도록 한다.

============================================================
1. 변경 대상
============================================================

주요 대상:
- Lathe / Turning 가공 시스템
- Chamfer Tool
- Tool Contact / Material Removal
- TurningProfile
- Chamfer Geometry
- Workpiece Visual Mesh

관련 기준 문서:
- Section 8 Turning Geometry — Round Profile
- Section 9 Visual Mesh
- Section 11.11 실제 절삭 발생 조건
- Section 12 MVP 공구
- Section 14 모따기

이번 PATCH는 Quest, Measurement, Inventory, Save, Dialogue 등
모따기와 직접 관계없는 시스템의 동작을 변경하지 않는다.

============================================================
2. 기존 동작
============================================================

기준 문서에서는 모따기에 대해 다음을 요구한다.

- 모따기 바이트 선택
- 지정 가장자리에 Chamfer 생성
- 프로파일에 경사 구간 반영
- 최종 형상 판정에서 존재 여부 확인 가능

기존 ChamferFeature 개념:
- Position
- Width
- Angle(optional)
- IsValid

그러나 이 정의만으로는 모따기가 플레이어의 실제 공구 조작 결과가 아니라
별도 기능 또는 고정 Feature 생성 명령처럼 구현될 가능성이 있다.

또한 현재 구현에서 모따기 바이트의 시각적/절삭 형상이
실제 45° 모따기 작업과 일치하지 않는 경우 이를 수정해야 한다.

============================================================
3. 변경 후 동작
============================================================

[핵심 규칙]

모따기는 별도 버튼 또는 자동 Feature 생성 명령으로 수행하지 않는다.

플레이어가:
1. 모따기 바이트를 선택하고
2. 바이트를 직접 이동시키며
3. 45° Cutting Edge가 공작물 모서리에 실제 접촉하면
4. 접촉 및 이송량에 따라 재료가 제거되고
5. TurningProfile에 45° 경사면이 생성되어야 한다.

즉:

45° Chamfer Tool
→ 실제 Tool/Workpiece Contact
→ Material Removal
→ TurningProfile 변경
→ 45° Chamfer Geometry 생성
→ Visual Mesh 갱신

의 흐름을 사용한다.

============================================================
4. 모따기 바이트 형상
============================================================

모따기 바이트의 유효 절삭면은 공작물의 Z축/외경 프로파일 기준으로
45° 경사 절삭을 만들 수 있는 방향으로 정의한다.

필수:
- 화면에서 바이트의 절삭 방향이 45°임을 식별할 수 있어야 한다.
- 시각적 Tool 형상과 실제 Collision/Cutting Geometry가 서로 모순되면 안 된다.
- 단순히 Sprite/Mesh만 45°로 돌리고 절삭 계산은 기존 직각 방식으로 두면 안 된다.

복잡한 실제 바이트 형상을 Primitive 조합으로 억지 제작하지 않는다.

현재 프로젝트에 적절한 외부 Tool Art/Mesh가 없다면:
- 기능 검증에 필요한 최소 Cutting Edge 표현만 코드/간단 Geometry로 구현한다.
- 완성형 외형이 필요한 경우 EXTERNAL ART REQUIRED로 명시한다.
- 임의의 복잡한 Primitive 조합을 완성형 아트로 취급하지 않는다.

============================================================
5. 접촉 기반 모따기
============================================================

모따기 생성 조건:

- Workpiece가 장착되어 있음
- Spindle이 회전 중임
- 현재 Tool이 Chamfer Cutting이 가능한 Tool임
- 현재 Lathe State가 절삭 가능한 상태임
- Tool의 유효 45° Cutting Edge가 Workpiece Geometry와 실제 접촉함

위 조건을 모두 만족할 때만 재료를 제거한다.

접촉하지 않은 상태에서는 Geometry가 변경되면 안 된다.

============================================================
6. 모따기 크기
============================================================

모따기 크기는 고정값 버튼으로 결정하지 않는다.

플레이어가 바이트를 얼마나 깊게 이송했는지에 따라
생성되는 45° 경사면의 크기가 달라져야 한다.

예:

얕은 접촉
→ 작은 Chamfer

더 깊은 이송
→ 더 큰 Chamfer

과도한 이송
→ 과도하게 큰 Chamfer / 실제 Geometry 과가공

따라서 플레이어가 실수로 너무 깊게 가공한 모따기를
자동으로 목표 크기로 보정하거나 복구해서는 안 된다.

============================================================
7. Geometry 규칙
============================================================

모따기는 화면 효과가 아니라 실제 Workpiece Geometry 변경이어야 한다.

TurningProfile은 모따기 결과를 표현할 수 있는 경사 구간을 가져야 한다.

45° 모따기에서는 X/Z 방향 제거량의 관계가
45° 경사면을 형성하도록 일관되게 계산되어야 한다.

주의:
Turning 내부 Geometry가 Radius 기준인 기존 원칙을 유지한다.
Player-Facing 치수 및 측정 의미는 Diameter 기준이라는 기존 규칙도 변경하지 않는다.

Geometry 변경 후:
- TurningProfile
- Workpiece 상태
- Visual Mesh

가 서로 동일한 결과를 나타내야 한다.

============================================================
8. 반복 절삭
============================================================

동일 모서리를 여러 번 가공할 수 있다.

이미 작은 모따기가 존재하는 상태에서
45° Cutting Edge를 다시 접촉시키고 더 깊게 이송하면
기존 경사면을 기준으로 추가 재료가 제거되어 더 큰 모따기가 될 수 있다.

단:
- 재료를 다시 추가하지 않는다.
- 이전 모따기를 자동 초기화하지 않는다.
- 목표값으로 Snap하지 않는다.

============================================================
9. 삭제 / 폐기 규칙
============================================================

다음 방식이 존재한다면 Player-Facing 정식 가공 동작에서는 제거하거나 사용하지 않는다.

- "모따기 생성" 버튼을 누르면 즉시 Chamfer 생성
- 모서리를 클릭하면 고정 크기 Chamfer 생성
- Tool 접촉 없이 ChamferFeature 직접 추가
- 항상 동일 Width의 Chamfer 생성
- 목표 치수에 자동 Snap
- 과가공된 Chamfer 자동 복구

ChamferFeature 데이터 구조 자체는
평가/Geometry 표현에 실제로 필요하다면 유지할 수 있다.

단, Feature 존재 자체가 재료 제거를 대신해서는 안 된다.

============================================================
10. 기존 시스템 유지 규칙
============================================================

다음 기존 규칙은 그대로 유지한다.

- Spindle OFF 상태에서는 절삭 불가
- 절삭 Tool이 접촉하지 않으면 절삭 불가
- Workpiece Geometry는 재료 제거 방식
- 과가공 자동 복구 금지
- 내부 Turning 계산은 Radius 사용 가능
- Player-Facing 치수는 Diameter
- 가공 결과는 실제 Geometry 기준으로 평가
- 공작물 재고정/Orientation 시스템 유지
- 실제 Orthographic 4 View 유지
- Player-Facing UI 한국어 유지

============================================================
11. Codex 구현 지시
============================================================

한 번에 전체 시스템을 재작성하지 않는다.

STEP 1 — AUDIT

먼저 현재 프로젝트에서 다음을 확인한다.

- Chamfer Tool 정의 위치
- Tool visual/prefab 구조
- Tool contact 판정 구조
- Material Removal 구현 위치
- TurningProfile 변경 방식
- ChamferFeature 사용 여부
- Visual Mesh 생성 방식

변경 전에 관련 파일 목록과 현재 모따기 처리 흐름을 요약한다.

불필요한 파일은 수정하지 않는다.


STEP 2 — 45° TOOL

현재 모따기 바이트의:
- 시각 방향
- Cutting Edge 방향
- 실제 절삭 계산

을 확인하고 45° 기준으로 일치시킨다.

화면만 회전시키는 수정으로 끝내지 않는다.


STEP 3 — CONTACT CUTTING

기존 Material Removal 계층을 최대한 재사용하여
45° Cutting Edge와 Workpiece의 접촉에 따른 재료 제거를 구현한다.

Chamfer 전용 버튼/명령이 Geometry를 직접 생성하는 구조가 있다면
정식 플레이 경로에서는 제거하거나 우회한다.


STEP 4 — GEOMETRY / MESH

접촉 결과가 TurningProfile의 실제 경사 구간으로 저장되는지 확인한다.

Geometry 변경 직후 Visual Mesh를 갱신하여
화면에서도 동일한 45° 모따기가 보여야 한다.


STEP 5 — VALIDATION

다음 테스트를 수행한다.

A. Tool이 떨어져 있음
→ Geometry 변경 없음

B. Spindle OFF + Tool 접촉
→ Geometry 변경 없음

C. Spindle ON + Chamfer Tool 접촉
→ 45° 경사 생성

D. 얕게 이송
→ 작은 모따기

E. 더 깊게 이송
→ 더 큰 모따기

F. 기존 모따기에 다시 접촉
→ 추가 절삭 가능

G. 과도하게 이송
→ 과가공된 형상이 그대로 남음

H. 저장된 Geometry와 Visual Mesh 비교
→ 동일한 45° 형상

============================================================
12. PASS 조건
============================================================

PASS:

- 모따기 바이트의 유효 절삭면이 45° 기준으로 동작한다.
- 시각적 Tool 방향과 실제 절삭 방향이 일치한다.
- 바이트가 공작물 모서리에 실제 접촉해야만 모따기가 발생한다.
- Spindle OFF에서는 모따기가 발생하지 않는다.
- 바이트 이송 깊이에 따라 모따기 크기가 달라진다.
- 반복 접촉/이송으로 추가 절삭할 수 있다.
- 모따기 결과가 TurningProfile 실제 Geometry에 저장된다.
- Visual Mesh가 실제 Geometry를 반영한다.
- 과가공을 자동 보정하지 않는다.
- 기존 선삭/재고정/측정 시스템을 불필요하게 파괴하지 않는다.

============================================================
13. FAIL 조건
============================================================

FAIL:

- 버튼 하나로 모따기가 생성된다.
- 모서리 클릭만으로 고정 크기 모따기가 생성된다.
- Tool이 접촉하지 않았는데 Geometry가 변경된다.
- Spindle OFF에서도 모따기가 생성된다.
- 항상 동일 크기의 Chamfer가 생성된다.
- 화면의 바이트만 45°이고 실제 절삭은 직각이다.
- Visual Mesh만 변하고 TurningProfile은 변하지 않는다.
- TurningProfile만 변하고 화면 형상이 갱신되지 않는다.
- 일반 황삭 바이트가 의도하지 않은 자동 모따기를 만든다.
- 과가공 결과가 목표 Chamfer 크기로 자동 복구된다.
- 기존 정상 선삭 동작이 깨진다.

============================================================

============================================================

회전 중인 공작물의 모서리에 접촉시키고,
이송 깊이에 따라 실제 45° 모따기 형상을 만들어낼 수 있다."
