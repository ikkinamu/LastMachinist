LAST MACHINIST — CODEX PATCH_002 REVISION 5
HANDWHEEL ZERO SET / 영점 설정 기능

[IMPORTANT]
이 파일은 기존 PATCH_002의 추가 수정 작업지시서다.
새 PATCH 번호를 만들지 않는다.

현재 Handwheel 이송 규칙은 유지한다.

×1 기준:
90° = 1 mm
180° = 2 mm
270° = 3 mm
360° = 4 mm

이번 REV5의 목적은 공구의 실제 위치를 움직이지 않고,
현재 위치를 기준으로 Handwheel 다이얼 표시만 0으로 맞출 수 있는
'영점 설정' 기능을 추가하는 것이다.

============================================================
1. 기능 개념
============================================================

플레이어가 [영점 설정] 버튼을 누르면:

- 공구 실제 위치는 변하지 않는다.
- X/Z Axis의 실제 좌표는 변하지 않는다.
- 공작물과 공구의 상대 위치도 변하지 않는다.
- 절삭 Geometry 상태도 변하지 않는다.
- 현재 위치를 기준으로 해당 Handwheel의 표시값만 0으로 재설정한다.
- Wheel_Disc의 숫자 0이 Fixed_Pointer를 가리키도록 표시를 갱신한다.

즉 이 기능은 '원점 복귀'가 아니다.

공구를 원점으로 이동시키는 기능이 아니라
현재 위치를 새로운 다이얼 영점으로 잡는 기능이다.

Player-Facing 명칭은:

영점 설정

을 사용한다.

'원점'이라는 표현은 기계 원점 복귀와 혼동될 수 있으므로
버튼 이름으로 사용하지 않는다.

============================================================
2. 예시
============================================================

예시 A:

현재 X축 실제 위치 = 12.7 mm
다이얼 표시 = 2.7 mm 상당

플레이어가 X축 [영점 설정] 클릭

결과:

X축 실제 위치 = 12.7 mm  ← 변화 없음
공구 위치 = 변화 없음
다이얼 표시 = 0
Wheel_Disc의 0 = Fixed_Pointer 위치

이후 +90° 회전:

실제 X축 위치 = 13.7 mm
새 영점 기준 표시 = +1.0 mm


예시 B:

현재 Z축 실제 위치 = -8.4 mm

Z축 [영점 설정] 클릭

결과:

실제 Z축 위치 = -8.4 mm 유지
표시 기준만 0으로 변경

이후 -180° 회전:

실제 Z축 위치 = -10.4 mm
새 영점 기준 표시 = -2.0 mm

============================================================
3. 실제 좌표와 표시 좌표 분리
============================================================

반드시 다음 개념을 분리한다.

A. Actual Axis Position
실제 공구/축의 물리적 위치.
영점 설정으로 절대 변경하지 않는다.

B. Display Zero Offset
플레이어가 영점 설정을 누른 순간의 기준 위치.

C. Relative Dial Reading
현재 실제 위치와 Display Zero Offset의 차이.

개념:

relativeReading =
actualAxisPosition - displayZeroOffset

[영점 설정] 실행 시:

displayZeroOffset = actualAxisPosition

따라서 즉시:

relativeReading = 0

이 구조를 사용한다.

============================================================
4. 절대 금지
============================================================

영점 설정 시 다음 동작은 금지한다.

- actualAxisPosition = 0
- Tool Transform을 원점으로 이동
- X/Z축 실제 Transform 변경
- 공작물 이동
- TurningProfile 변경
- 절삭 결과 변경
- Machine Coordinate 초기화
- 이동 한계 계산 초기화
- 실제 Handwheel 이동 누적량을 물리적으로 되돌림
- Quest/Measurement 데이터 임의 초기화

영점 설정은 표시 기준만 바꾼다.

============================================================
5. Wheel_Disc 표시
============================================================

기존 Wheel_Disc 규칙을 유지한다.

12시 = 0
3시 = 1
6시 = 2
9시 = 3

Fixed_Pointer는 Wheel 외곽 12시 방향에 고정한다.

[영점 설정]을 누르면:

Wheel_Disc의 시각적 기준을 갱신하여
숫자 0이 Fixed_Pointer를 정확히 가리키게 한다.

중요:

이 시각적 재설정 과정에서
Axis Movement Command를 호출하면 안 된다.

Wheel_Disc 표시만 재정렬한다.

============================================================
6. 이후 회전
============================================================

영점 설정 후에도 기존 이송 규칙은 그대로 유지한다.

×1:

+90° → 실제 +1 mm
+180° → 실제 +2 mm
+360° → 실제 +4 mm

-90° → 실제 -1 mm

즉 영점 설정은 이송 비율을 변경하지 않는다.

단지 플레이어가 현재 위치를 기준으로
이후 이동량을 읽을 수 있게 한다.

============================================================
7. X축 / Z축
============================================================

X축과 Z축은 영점을 독립적으로 관리한다.

예:

X 영점 설정
→ X Display Zero Offset만 변경
→ Z 영점은 그대로 유지

Z 영점 설정
→ Z Display Zero Offset만 변경
→ X 영점은 그대로 유지

한 버튼으로 두 축의 영점을 동시에 초기화하지 않는다.

각 Handwheel 또는 각 축 UI에
독립적인 [영점 설정] 기능을 제공한다.

============================================================
8. UI
============================================================

각 Handwheel 주변의 기존 UI 레이아웃을 확인한 뒤
가독성을 해치지 않는 위치에 버튼을 추가한다.

Player-Facing 버튼 텍스트:

영점 설정

버튼은 어떤 축에 적용되는지 명확해야 한다.

예:

X축 Handwheel 영역
[영점 설정]

Z축 Handwheel 영역
[영점 설정]

또는 현재 선택 축 구조를 활용할 수 있으나,
사용자가 어떤 축의 영점을 설정하는지 모호하면 안 된다.

============================================================
9. 기존 PATCH_002 규칙 유지
============================================================

다음은 그대로 유지한다.

============================================================
10. 저장 / 상태 관리
============================================================

현재 프로젝트의 저장 시스템 구조를 AUDIT한다.

Handwheel의 영점 상태가 플레이 중 의미 있는 상태로 취급되는 구조라면
X/Z Display Zero Offset을 기존 Save 데이터 구조와 일관되게 저장/복원한다.

단, 저장 시스템 전체를 이번 PATCH 때문에 재설계하지 않는다.

씬 재로드나 저장/불러오기에서 영점을 유지해야 하는지
현재 프로젝트의 다른 기계 상태 보존 방식과 일관되게 처리한다.

임의로 Machine Coordinate를 저장값 0으로 덮어쓰지 않는다.

============================================================
11. Codex 작업 순서
============================================================

STEP 1 — AUDIT

현재 다음 구조를 확인한다.

- X/Z 실제 Axis Position 저장 위치
- Handwheel rotation 상태
- Wheel_Disc visual rotation
- HUD의 위치 표시값
- 기존 Axis Movement Command
- X/Z Handwheel UI Prefab
- Save/Load 관련 상태 관리

STEP 2 — DATA SEPARATION

Actual Axis Position과 Display Zero Offset을 분리한다.

X/Z 각각 독립적인 zero offset을 가진다.

STEP 3 — ZERO SET COMMAND

영점 설정 Command/메서드를 추가한다.

동작:

displayZeroOffset = currentActualAxisPosition

실제 Axis Position은 수정하지 않는다.

STEP 4 — WHEEL VISUAL RESET

영점 설정 후 Wheel_Disc의 0이
Fixed_Pointer를 가리키도록 시각 상태를 갱신한다.

이 과정에서 실제 축 이동 Command를 호출하지 않는다.

STEP 5 — UI

X/Z에 적용되는 [영점 설정] 버튼을 연결한다.

STEP 6 — MOVEMENT TEST

영점 설정 이후에도 90°=1mm 규칙이 유지되는지 확인한다.

STEP 7 — REGRESSION

선삭, 측정, 주축, 카메라, Handwheel 입력 등
기존 정상 기능을 확인한다.

13. PASS 조건
============================================================

- 영점 설정 시 공구 실제 위치가 전혀 움직이지 않음
- Actual Axis Position 유지
- 현재 위치가 Display Zero Offset으로 저장됨
- 상대 표시값 즉시 0
- Wheel_Disc의 0이 Fixed_Pointer를 가리킴
- X/Z 영점 독립 관리
- 이후 90°=1mm 규칙 정상 유지
- 영점 설정이 Axis Movement Command를 호출하지 않음
- 절삭 Geometry에 영향 없음
- 기존 정상 기능 유지

============================================================
14. FAIL 조건
============================================================

다음 중 하나라도 발생하면 완료로 처리하지 않는다.

- 영점 설정 시 공구가 실제로 이동함
- actualAxisPosition을 0으로 덮어씀
- Tool Transform을 원점으로 이동함
- 공작물 위치가 변경됨
- X 영점 설정이 Z 영점까지 변경함
- Z 영점 설정이 X 영점까지 변경함
- Wheel 표시만 0인데 상대 위치 계산은 이전 기준을 사용함
- 영점 설정 후 90°=1mm가 깨짐
- 영점 설정이 절삭/Geometry에 영향을 줌
- Fixed_Pointer가 회전함
- 버튼 이름이 '원점 복귀'처럼 실제 이동 기능으로 오해될 표현임

16. 완료 정의
============================================================

현재 공구 위치를 그대로 유지한 상태에서
플레이어가 [영점 설정]을 누르면 해당 축의 표시 기준만 즉시 0이 되고,

그 이후 Handwheel을 회전하면 새 영점을 기준으로 표시값이 증가/감소하되,
실제 축은 기존 위치에서 연속적으로 움직여야 한다.
