10. BENCH DRILL MAJOR DISCOVERY

탁상드릴은 일반 Loot와 분리된 Major Discovery. 발견 전 Map/Quest UI에서
이름을 미리 노출하지 않는다. 발견 시 MajorDiscovery 기록 + Quest
Objective 갱신. 일반 Workpiece Inventory Item으로 취급하지 않고
Equipment/Workshop Progression으로 관리.

11. BENCH DRILL ROLE

Lathe Tailstock Drill: - 회전체 중심축 방향 Hole.

Bench Drill: - 판재/각재/직사각재 등 비회전체 포함 - 중심축에 제한되지
않는 일반 위치 Hole 기반.

따라서 Tailstock Drill과 Bench Drill을 같은 기능으로 취급하지 않는다.

이번 Phase 최소 목표는 발견→회수/복구→Workshop Equipment 등록/표시. 정밀
Bench Drill Simulator 전체는 후속 Phase 가능.

12. WORKPIECE SHAPE EXPANSION

최소 ShapeType: - RoundBar - SquareBar - RectangularBar - Plate - Tube

RoundBar 전용 Diameter+Length 구조에 모든 재료를 억지로 넣지 않는다.

권장 Geometry: RoundBar: Diameter, Length SquareBar: Width, Height,
Length RectangularBar: Width, Height, Length Plate: Width, Length,
Thickness Tube: OuterDiameter, InnerDiameter, Length 또는 OuterDiameter,
WallThickness, Length.

Tube는 ID 또는 WallThickness 중 하나를 내부 Source of Truth로 정해 중복
Truth를 피한다.

13. CURRENT GEOMETRY / INVENTORY

각 WorkpieceInstance는 실제 CurrentGeometry를 가진다.
NominalDimensions를 현재 실제 치수처럼 표시하지 않는다.

표시 예: - 환봉: Ø30 × 100.0 mm - 각봉: 30 × 30 × 120.0 mm - 직사각
봉재: 20 × 40 × 120.0 mm - 판재: 100 × 80 × t5.0 mm - 파이프: Ø40 × t3 ×
100.0 mm

Material Unknown이면 기존 IdentificationState에 따라 실제 Material
Truth를 숨긴다.

14. NON-STACK

Phase04 REV2 유지. WorkpieceInstance is NOT a Stack Item.

같은 판재 두 장도: - 별도 Row - 별도 InstanceId - 별도
Condition/Geometry

판재 x2처럼 합치지 않는다. Consumable Resource는 별도 규칙으로 Stack
가능.

15. EXPLORATION MATERIAL VARIETY

Abandoned Workshop에 환봉만 배치하지 않는다.

최소 Test Set: - RoundBar ≥1 - SquareBar 또는 RectangularBar ≥1 - Plate
≥1 - Tube ≥1

모두 기존 Inspect→Recover Flow 사용. 각 Instance는 Condition,
IdentificationState, CurrentGeometry 보유.

16. MACHINE COMPATIBILITY

ShapeType 기반으로 일반화.

Lathe: - RoundBar 기본 Compatible - Tube는 현재 구현 능력에 따라
조건부 - Plate/Square/Rectangular는 현재 미지원이면 Incompatible

Bench Drill: - Plate/Square/Rectangular/RoundBar/Tube를 향후
Fixture/Operation 규칙에 따라 지원

Milling: - Plate/Square/Rectangular 중심으로 향후 확장

미지원 Shape를 기존 Lathe에 억지로 로드하지 않는다. Incompatible 선택 시
이유를 표시하고 Item은 Available 상태 유지.

17. LATHE REGRESSION

기존 RoundBar: Inventory → 선택 → ActiveMachiningWorkpiece → Lathe →
Turning → Measurement → SaveLoad 흐름을 그대로 유지한다.

Shape 일반화 때문에 기존 Quest01/Repeatable Lathe Flow가 깨지면 FAIL.

18. SAVE / LOAD

각 Instance 저장: InstanceId / DefinitionId / ShapeType /
CurrentGeometry / Material Truth Reference / IdentificationState /
Condition / Ownership State / 기존 데이터.

Shape별 Geometry를 정확히 복원한다. Plate 100×80×t5 → Save→Continue →
동일 치수. 기존 RoundBar Save와 가능한 범위에서
Migration/Compatibility를 제공한다.

19. QUEST TRACKER

기존 “현재 행동” 규칙 유지.

예: 박성철과 이야기하자 → 지도에서 새로운 정보를 확인하자 → 버려진
작업장을 찾아가자 → 작업장 내부를 조사하자 → 발견한 장비를 확인하자 →
장비를 회수할 방법을 확인하자 → 작업장으로 돌아가자

탁상드릴 발견 전에는 Tracker가 이름을 스포하지 않는다.

20. PACING

지역 진입 5초 만에 Major Discovery를 주지 않는다. 지역 분위기 →
재료/Prop 조사 → 작업장 위치 파악 → 내부 진입 → 발견 순서를 경험하게
한다. 반대로 불필요한 미로/긴 이동으로 시간을 끌지 않는다.
